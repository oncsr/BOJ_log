### 문제 설명

<p>Dominik je kupio automobile za svoj novi vozni park. Poznato je da Audi košta A tisuća eura, Nissan B tisuća eura, a Ferrari C tisuća eura.</p>

<p>Nije nam poznato koliko je Dominik kupio Audija, koliko Nissana, a koliko Ferrarija, ali načuli smo sljedeće:</p>

<ul>
	<li>Kupio je najmanje jedan, a najviše N automobila svakog proizvođača.</li>
	<li>Ukupni iznosi potrošeni na Audije, Nissane i Ferrarije međusobno su različiti.</li>
	<li>Na Audije je potrošeno najviše, a na Ferrarije najmanje novca.</li>
</ul>

<p>Iako nam ove informacije nisu dovoljne da zaključimo koliko je kojih automobila kupio Dominik, možemo izbrojiti koliko mogućnosti postoji. Preciznije, koliko ima trojki (X, Y, Z) takvih da je Dominik mogao kupiti X Audija, Y Nissana i Z Ferrarija u skladu s gornjim informacijama?</p>

### 입력 

 <p>U prvom retku nalazi se prirodan broj N (1 ≤ N ≤ 1 000 000) iz teksta zadatka.</p>

<p>U sljedećem retku nalaze se tri prirodna broja A, B i C (1 ≤ A, B, C ≤ 1000) iz teksta zadatka.</p>

### 출력 

 <p>U jedini redak ispiši traženi broj mogućnosti.</p>
